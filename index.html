Hermes

A personal, single-user agent for the owner's own Google Workspace account.

What this application is

Hermes is a private automation agent that runs locally on the computer of its single owner. It is not a public service, it is not offered to the general public, and it has no other users. The only Google account it can ever access is the owner's own account, which the owner authorizes directly through Google's OAuth consent screen.

What it does

When the owner asks it to, Hermes connects to the owner's Google account and:

  • reads, searches, drafts and sends Gmail messages;
  • reads, creates and deletes Google Calendar events;
  • searches, uploads, downloads and organizes files in Google Drive;
  • reads and writes Google Sheets spreadsheets;
  • reads and writes Google Docs documents;
  • reads the owner's Google Contacts.

Every action is initiated by the owner in a conversation with the agent. The application performs no background scanning, no bulk collection, and no automated processing of the account's contents.

Who it is for

Exactly one person: the owner of the Google account that grants access. There are no sign-ups, no accounts, and no way for anyone else to use this application against their own Google data.

Data handling

Google user data is used only to carry out the tasks the owner requests, and only within the owner's own account. Data is not sold, is not used for advertising, and is not shared with third parties except as described in the privacy policy. Full details are in the Privacy Policy.

Hermes is an independently developed personal project. It has not been submitted for Google's app verification review, which is why the consent screen shows an “unverified app” warning. That warning is expected and is safe to acknowledge for the single account that authorizes it.
