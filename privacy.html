Privacy Policy

Hermes — personal Google Workspace agent. Last updated 17 October 2026.

1. Scope

This policy describes how Hermes (the “Application”) accesses, uses, stores, and shares data obtained from Google APIs. The Application is a personal tool operated by, and serving, a single individual: the owner of the Google account that authorizes it. It is not offered to the public and has no other users.

2. Google user data the Application accesses

When the owner grants access through Google's OAuth consent screen, the Application may access:

  • Gmail — read messages, send messages, and modify labels (gmail.readonly, gmail.send, gmail.modify);
  • Google Calendar — read, create, and delete events (calendar);
  • Google Drive — search, read, upload, organize, and delete files (drive);
  • Google Sheets — read and write spreadsheet values (spreadsheets);
  • Google Docs — read and write document content (documents);
  • Google Contacts — read contact names, addresses, and phone numbers (contacts.readonly).

3. How that data is used

Google user data is used solely to perform the specific tasks the owner requests in conversation with the Application — for example, summarizing an email, listing upcoming events, or updating a spreadsheet cell. The Application does not scan, index, or analyze the account's contents on its own initiative, and performs no background collection.

4. How that data is stored

The Application stores a Google OAuth refresh token on the owner's own computer, in the owner's local profile directory. This token is what allows the Application to act on the owner's behalf without re-authorizing each time. It is stored only on that machine and is never transmitted to the developer.

Message bodies, file contents, and calendar entries are retrieved on demand and are not retained in any database or long-term store by the Application. The owner may delete the token at any time, which immediately ends the Application's access.

5. How that data is shared

Google user data is not sold, and is not used or transferred for advertising, profiling, or any purpose unrelated to the owner's requests. It is not shared with third parties, with one necessary exception:

  • AI model processing. Hermes is an AI agent. To interpret the owner's request and produce a response, the content the Application reads from Google — such as an email's text or a spreadsheet's cells — is sent to the AI model provider the owner has configured, over an encrypted connection, for the sole purpose of processing that request. The owner chooses and controls that provider. No Google user data is sent anywhere else.

The Application's use of Google user data complies with the Google API Services User Data Policy, including its Limited Use requirements.

6. Retention and deletion

  • Revoking access — from the Application, or from myaccount.google.com/permissions — immediately and permanently ends the Application's ability to reach the account, and deletes the locally stored token.
  • Because the Application keeps no server-side copy of Google user data, there is nothing further to delete on any server when access is revoked.
  • Content already delivered into a conversation may persist in the owner's local conversation history until the owner deletes it.

7. Security

Communication with Google APIs and with the AI model provider uses HTTPS. The stored OAuth token is readable only by the owner's local user account.

8. Children

The Application is not directed at children and is not available to the public.

9. Changes

Any change to this policy will be published on this page with an updated revision date.

10. Contact

Questions about this policy or about the handling of Google user data may be directed to talariabot@gmail.com.
